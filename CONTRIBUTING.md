# Contributing

openzoopa uses the Developer Certificate of Origin (DCO), not a contributor license agreement.

By contributing, you certify the DCO 1.1 terms at <https://developercertificate.org/> and sign off each commit with:

```text
Signed-off-by: Your Name <you@example.com>
```

Use `git commit -s` to add the sign-off automatically.

Licensing follows `LICENSING.md`: server-side code is AGPL-3.0-only and endpoint/protocol/library code is Apache-2.0. Do not add a dependency from an Apache-2.0 crate to an AGPL-3.0-only crate.
